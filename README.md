# Тестовое задание: «Матчи тура»

Привет! Это небольшое задание примерно на **1 час**. Нам интересно не количество фич, а то, как вы разбираетесь в коде и доводите задачу до результата.

- Если за час не успели всё — сдавайте как есть и напишите, что осталось. Это нормально.
- Пожалуйста, не тратьте больше 2 часов.
- **ИИ можно и нужно** — Claude, Cursor, ChatGPT, Copilot, что угодно. Если всё сделал агент, а вы проверили результат, — отлично. Важно одно: код вы должны понимать.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run web      # откроется в браузере — телефон не нужен
# или
npm start        # QR-код для Expo Go на телефоне
```

Проект — Expo + React Native + TypeScript. Если раньше вы писали только на React для веба, это не страшно: вместо `div` здесь `View`, вместо `span` — `Text`, вместо `button` — `Pressable`, списки — `FlatList`.

## Часть 1. Экран «Матчи тура»

Файл `src/screens/MatchesScreen.tsx` сейчас пустой. Сделайте экран:

1. Загрузите матчи с сервера: адрес — `MATCHES_URL` в `src/config.ts`. Пример ответа лежит в `data/matches.json`.
2. Покажите список матчей. В карточке: хозяева и гости, счёт (если он есть), дата и время начала **в часовом поясе устройства**, статус по-русски.
3. Пока данные загружаются, покажите загрузку. При ошибке — сообщение и кнопку «Повторить». Если матчей нет — понятный пустой экран.
4. Фильтр над списком: **Все / Предстоящие / Завершённые**. Куда отнести матчи с другими статусами, решите сами и коротко объясните это в `SOLUTION.md`.
5. Кнопка «Обновить» (или pull-to-refresh) и подпись «Обновлено N сек назад» — для неё есть готовый компонент `UpdatedAgo`.

Присмотритесь к данным: в них есть неочевидные случаи.

## Часть 2. Чужой код

В проекте уже есть компоненты, которые написал коллега:

- `src/components/FavoriteButton.tsx` — звёздочка «в избранное»;
- `src/hooks/useFavorites.ts` — хук со списком избранных матчей;
- `src/components/UpdatedAgo.tsx` — подпись «Обновлено N сек назад».

Подключите звёздочку к каждой карточке матча. От тестировщика пришли жалобы:

1. «Звёздочки горят у всех матчей сразу, хотя я ничего не добавлял. Нажатие срабатывает непредсказуемо: то ничего не меняется, то звезда гаснет вместо того, чтобы загореться».
2. «„Обновлено N сек назад“ застывает на одном числе и не сбрасывается после обновления».

Найдите причины и исправьте. В `SOLUTION.md` для каждой проблемы напишите 1–3 предложения своими словами: **почему** так происходило. Это самая важная часть задания.

## Часть 3. `SOLUTION.md`

Заполните файл `SOLUTION.md` по шаблону внутри. Коротко, без воды — пары строк на пункт достаточно.

## Если останется время

Любое одно на выбор: поиск по названию клуба, сохранение избранного между запусками, тест на логику фильтра, тёмная тема — или своя идея. Напишите в `SOLUTION.md`, что выбрали и почему.

## Как сдать

1. Сделайте копию репозитория на GitHub или GitLab (публичную) — кнопкой «Use this template» или через fork.
2. Коммитьте по ходу работы — хотя бы 3–5 коммитов, а не один в конце. Нам важна история.
3. Пришлите ссылку на репозиторий в ответ на сообщение с заданием.

Можно добавлять любые библиотеки, если объясните зачем. Приложение должно запускаться командой `npm run web` после `npm install`.

## На что мы смотрим

- Работает ли экран: данные, состояния, фильтр, звёздочки.
- Как обработаны данные: не теряются ли неочевидные случаи.
- Понятен ли код: компоненты, типы, названия.
- Объяснения в `SOLUTION.md`: понимаете ли вы, что происходит в коде и почему.

На красоту дизайна не смотрим: аккуратно и читаемо — достаточно.
