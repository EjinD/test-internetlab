# Решение

## Сколько заняло

Время отдельно не засекал; основное время ушло на экран, обработку данных и исправление двух багов.

## Что сделано и что не успел

- Реализован экран «Матчи тура»: загрузка данных, карточки, счёт, локальные дата и время, русские статусы.
- Добавлены загрузка, ошибка с повторным запросом, пустое состояние, фильтры, ручное и pull-to-refresh обновление.
- Ответ сервера проверяется перед использованием; некорректные данные приводят к сообщению об ошибке, а не к падению списка.
- Избранное работает в рамках текущего запуска приложения; сохранение после перезапуска не добавлял.

## Решения

В «Предстоящие» входят матчи со статусом `scheduled`, в «Завершённые» — `finished`. Матчи `live`, `postponed` и матчи с неизвестными статусами оставлены в «Все»: текущий матч ещё не завершён, а у перенесённого может не быть даты. Если `startsAt` отсутствует, равен `null` или содержит некорректную дату, показывается «Дата не определена». При отсутствии счёта выводятся прочерки, а счёт `0 : 0` отображается как полноценный результат.

## Баги из части 2

1. **Звёздочки:** `indexOf()` возвращает `-1`, если id не найден, а `Boolean(-1)` — `true`; при этом индекс `0` превращался в `false`. Дополнительно массив изменялся на месте и в состояние передавалась та же ссылка. Проверка теперь использует `includes()`, а переключение создаёт новый массив через функциональное обновление состояния.
2. **«Обновлено N сек назад»:** интервал использовал `seconds` из замыкания первого рендера, поэтому число застывало; также интервал не очищался, а проп `since` игнорировался. Компонент рассчитывает прошедшие секунды от `since`, обновляет текущее время раз в секунду и очищает интервал при размонтировании или изменении `since`.

## Как я использовал ИИ

Использовал ChatGPT для анализа исходного кода, подготовки реализации и ревью. При проверке первоначального варианта учёл, что проверки только массива `matches` недостаточно: добавил проверку структуры каждой записи и счёта. Локальная проверка выполнена: `npm ci` завершилась успешно, `npm run typecheck` прошла без ошибок, `npm run web` собрала web-приложение (`Web Bundled`). Предупреждения npm об уязвимостях отдельно требуют просмотра через `npm audit`; визуальная проверка сценариев выполняется вручную.
